Open Roles

Help take AI-native memory from architecture to a working system.

Chip · RTL

Digital IC Engineer

Chip Design · RTL
30K–45Kper month

Design and verify digital logic for next-generation AI memory chips.

Responsibilities

  • Define module behavior and microarchitecture; implement RTL
  • Build simulation tests, review coverage, and debug failures
  • Support synthesis, timing, and power analysis to improve PPA
  • Integrate with systems teams and document design decisions

Qualifications

  • Background in electrical or computer engineering, IC design, or a related field
  • Proficiency in Verilog/SystemVerilog and digital timing fundamentals
  • Ability to analyze waveforms and debug regression failures
  • FPGA, memory, or AI chip project experience is a plus

AI · Infra

AI Infrastructure Engineer

AI Infra Engineer
40K–50Kper month

Build the infrastructure connecting large models to new memory hardware.

Responsibilities

  • Build model inference, device runtime, or data service components
  • Profile throughput, latency, and memory use; optimize data paths
  • Develop benchmarks, monitoring, and diagnostic tools
  • Work with chip and AI teams on hardware/software integration

Qualifications

  • Background in computer science, software engineering, or a related field
  • Proficiency in C++ or Python and familiarity with Linux
  • Experience profiling systems and debugging complex issues
  • AI model inference, CUDA, or storage systems experience is a plus
