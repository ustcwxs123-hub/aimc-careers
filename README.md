# Aimc Careers

Static careers website for the Professional English assignment.
USTC研究生专业英语作业

## Local preview

Serve this directory with any static HTTP server. For example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## Deployment

The site is compatible with GitHub Pages and requires no build step. Publish the repository root from the `main` branch.

## Contents

- `index.html` — complete page, styles, and interactions
- `assets/logo-mark.png` — Aimc logo
- `assets/poster.png` — recruitment poster
- `assets/qr-code.png` — QR code linking to the published careers website
